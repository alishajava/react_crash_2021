    ☁️ GitHub에 자동 저장

    설정하기 (처음 한 번, 약 2분)
    1. GitHub 토큰 만들기 페이지를 엽니다. (gist 권한만 체크돼 있으면 됩니다)
    2. Expiration(만료)을 고르고 맨 아래 Generate token을 누릅니다.
    3. 나온 ghp_… 글자를 복사해 아래에 붙여 넣고 연결을 누릅니다.

    토큰은 이 브라우저에만 보관되고, 할 일은 내 GitHub 계정의 비공개 Gist에 저장됩니다. 다른 기기에서도 같은 토큰으로 연결하면 같은 목록을 봅니다. 공용 컴퓨터에서는 쓰고 나서 "연결 끊기"를 눌러 주세요.

    이 기기와 GitHub의 목록이 서로 달라요. 어느 쪽을 쓸까요?
